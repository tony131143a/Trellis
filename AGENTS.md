# Arbor Instructions

These instructions are for AI assistants working in this project.

This project is managed by Arbor. The working knowledge you need lives under `.arbor/`:

- `.arbor/workflow.md` — development phases, when to create tasks, skill routing
- `.arbor/spec/` — package- and layer-scoped coding guidelines (read before writing code in a given layer)
- `.arbor/workspace/` — per-developer journals and session traces
- `.arbor/tasks/` — active and archived tasks (PRDs, research, jsonl context)

If a Arbor command is available on your platform (e.g. `/arbor:finish-work`, `/arbor:continue`), prefer it over manual steps. Not every platform exposes every command.

If you're using Codex or another agent-capable tool, additional project-scoped helpers may live in:
- `.agents/skills/` — reusable Arbor skills
- `.codex/agents/` — optional custom subagents

Managed by Arbor. Edits outside this block are preserved; edits inside may be overwritten by a future `arbor update`.
